K. Dharhas — Java Lab Records Website
=====================================

Student: K. Dharhas
Roll Number: 25EU02082
Theme: Light blue and white, with optional dark mode
Layout: Sidebar dashboard with responsive mobile menu

Files:
- index.html: Website structure
- style.css: Design and responsive styling
- script.js: Week cards, search, filters, chart, theme switch
- pdfs/week-01.pdf through pdfs/week-12.pdf: Uploaded lab records

Run locally:
1. Extract the ZIP.
2. Open index.html in a browser, or use the VS Code Live Server extension.

Publish on GitHub Pages:
1. Create/open the repository for the website.
2. Upload the contents of this folder (index.html, style.css, script.js, pdfs/, README.txt).
3. In GitHub, open Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.

Note: Week card titles are short labels to help navigation; each View PDF button opens the original uploaded weekly PDF.
